# OctoAcme Project Management Docs

Welcome! This directory contains OctoAcme’s living documentation for running successful cross-functional projects.

## Overview

OctoAcme’s approach is:
- Customer-first and data-driven
- Focused on delivering value with small, measurable increments
- Transparent about roles, process, and communication
- Centred on continuous improvement
